## 📌 Project Overview

The **Uber Ride Booking & Business Performance Dashboard** is an interactive Power BI project developed to analyse ride bookings, revenue performance, vehicle categories, customer behaviour, and geographical trends.

This dashboard transforms ride-booking data into meaningful business insights through interactive visualisations, KPI cards, charts, and filters.

It helps understand booking performance, revenue trends, cancellation patterns, customer behaviour, and vehicle-wise performance.

## 📊 Dashboard Pages

### 🏠 1. Home

The Home page serves as the landing page of the dashboard.

**Features:**
- Introduction to Uber.
- Navigation to all dashboard sections.
- Clean and user-friendly dashboard design.
- Vehicle category selection.

### 📈 2. Overview

The Overview page provides a high-level summary of overall ride-booking performance.

**Key Performance Indicators (KPIs):**
- Completed Bookings: 93K
- Lost Bookings: 57K
- Revenue: 52M
- Total Distance: 2.51M

**Business Analysis:**
- Monthly Completed Bookings Trends.
- Monthly Revenue Trends.
- Revenue by Vehicle Type.
- Top Locations by Booking Count.
- Monthly and Quarterly Performance Analysis.

### 🚘 3. Vehicle Analysis

This page focuses on analysing booking and revenue performance across different vehicle categories.

**Key Analysis:**
- Revenue by Vehicle Type.
- Monthly Revenue Trends by Vehicle.
- Vehicle-wise Booking Count.
- Completed Bookings by Vehicle.
- Lost Bookings by Vehicle.
- Average Distance by Vehicle.
- Vehicle Contribution Percentage.

**Vehicle Categories:**
- Auto
- Bike
- Go Mini
- Go Sedan
- Premier Sedan
- Uber XL

### 💰 4. Revenue Analysis

This page provides insights into revenue trends and payment methods.

**Key Analysis:**
- Monthly Revenue Trends.
- Quarterly Revenue Trends.
- Booking Value by Payment Method.
- Revenue Performance Analysis.
- Interactive Month and Quarter Selection.

**Payment Methods:**
- UPI
- Cash
- Uber Wallet
- Credit Card
- Debit Card

### 👥 5. Rider Analysis

This page focuses on customer behaviour, booking cancellations, and rider segmentation.

**Key Analysis:**
- Booking Cancellation Reasons.
- Customer Booking Analysis.
- Driver Booking Analysis.
- Incomplete Booking Analysis.
- First-Time Riders.
- Return Riders.
- Regular Riders.
- Customer-wise Booking Details.

### 📍 6. Location Analysis

This page analyses ride distance and booking patterns across different locations and time slots.

**Key Analysis:**
- Total Distance Trends.
- Monthly and Quarterly Distance Analysis.
- Distance by Vehicle Type.
- Location-wise Booking Performance.
- Day-wise and Time-slot Booking Analysis.
- Booking Distribution Across Weekdays.

**Location Highlights:**
- Khandsa
- Ashram

## 🚀 How to Use

1. Open the Google Drive link provided in the Project Files & Dataset section.
2. Download the Power BI (`.pbix`) file and required dataset.
3. Open the `.pbix` file using Microsoft Power BI Desktop.
4. Connect the dataset if prompted.
5. Update the data source path if necessary.
6. Refresh the data.
7. Explore all six dashboard pages using interactive filters and navigation.
